# شطرنج المعرفة

مسابقة معرفية بنظام الشطرنج بين الأقسام العلمية السبعة في كلية الإدارة والاقتصاد، جامعة الموصل.

## طريقة التشغيل

افتح الملف `index.html` في المتصفح. اللعبة ملف واحد ولا تحتاج تثبيتاً.

## القواعد

- يختار القسم نقلته على الرقعة، ثم يظهر السؤال.
- الإجابة الصحيحة تنفّذ النقلة. الخطأ أو انتهاء وقت السؤال يُفقد الدور.
- صعوبة السؤال حسب القطعة: البيدق سهل، الحصان والفيل والقلعة متوسط، الوزير والملك صعب.
- أسر قطعة يرفع الصعوبة درجة واحدة.
- البطولة بنظام خروج المغلوب مع قرعة عشوائية.

## الحقوق

- الفكرة: شعبة النشاطات الطلابية / كلية الإدارة والاقتصاد / جامعة الموصل
- تصميم وبرمجة: علي عبد الوهاب الصفار
